# 분석에 쓸 칸
## 돈 습관 (적은 돈으로 시작 가능한 행동)
- expense_tracking_frequency : 지출 기록 빈도
- budgeting_frequency : 예산 짜는 빈도
- financial_goal_setting : 돈 목표를 세우는지 (0/1)
- automatic_savings : 자동이체 저축 (0/1)
- dollar_cost_averaging : 적립식 투자 (0/1)
- credit_card_payment_behavior : 카드값 갚는 방식
## 생활 습관
- habit_tracking : 습관 기록 여부 (0/1)
- daily_planning : 하루 계획 여부 (0/1)
- exercise_days_per_week : 일주일 운동 일수
- books_read_per_year : 1년 독서 권수 (빈 값 4.15%)
- social_media_hours_per_day : 하루 SNS 시간
- wake_up_time : 일어나는 시각
## 정답 칸
- millionaire_status : 백만장자 여부 (0/1)
